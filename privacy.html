Privacy policy

Last updated: 18 November 2026

HermesAgent is a private application used by one individual, on their own infrastructure, to access their own Google account data.

What data is accessed

Gmail messages and metadata, Google Calendar events, and Google Drive files, solely through the Google APIs the account owner explicitly authorises.

How data is used

Data is processed locally to produce summaries and reminders for the account owner. It is not sold, shared, or transferred to third parties, and it is not used for advertising.

Storage

OAuth tokens are stored locally on the owner's server with restricted file permissions. No Google user data is stored on external servers.

Retention and deletion

Temporary copies are deleted after processing. Access can be revoked at any time via the Google Account permissions page, which immediately invalidates the stored token.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
